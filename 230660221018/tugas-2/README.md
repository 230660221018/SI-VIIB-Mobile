## Deskripsi

Program Dart sederhana untuk menghitung rata-rata skor dari beberapa komponen penilaian dan menentukan predikat akhir.

Program menggunakan `List<Map<String, Object>>`, fungsi, perulangan `for`, dan percabangan `if-else`.

```bash
