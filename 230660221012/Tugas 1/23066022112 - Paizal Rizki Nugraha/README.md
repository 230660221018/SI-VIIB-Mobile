## 1. Deskripsi Sistem

APK Catatan merupakan aplikasi berbasis mobile yang dirancang untuk membantu mahasiswa, pelajar, dan masyarakat umum dalam mencatat serta mengelola informasi penting dalam kegiatan sehari-hari.

Aplikasi ini bertujuan untuk mengatasi permasalahan pencatatan yang masih dilakukan secara manual menggunakan kertas atau melalui berbagai aplikasi yang terpisah. Kondisi tersebut dapat menyebabkan catatan mudah tercecer, sulit ditemukan kembali, dan informasi penting berisiko terlupakan.

Dengan adanya APK Catatan, pengguna dapat menyimpan, melihat, mengubah, dan menghapus catatan melalui perangkat smartphone. Aplikasi ini juga dirancang dengan antarmuka sederhana agar mudah digunakan kapan saja dan di mana saja.

### Karakteristik Aplikasi Mobile

Pengembangan APK Catatan didasarkan pada beberapa karakteristik aplikasi bergerak, yaitu:

1. **Interaksi Sentuh (Touch Interaction)**  
   Pengguna dapat melakukan aktivitas seperti menambahkan, mengedit, melihat, dan menghapus catatan secara langsung melalui layar sentuh smartphone.

2. **Konteks Bergerak (Mobility)**  
   Aplikasi dapat digunakan kapan saja dan di mana saja melalui perangkat smartphone sehingga pengguna tidak harus bergantung pada komputer untuk mengakses catatan.

3. **Layar Kecil (Small Screen)**  
   Aplikasi menggunakan desain antarmuka yang sederhana dan responsif agar informasi dapat ditampilkan dengan nyaman pada layar smartphone.

## 3. Fitur Utama Aplikasi

APK Catatan memiliki beberapa fitur utama yang direncanakan untuk mendukung aktivitas pencatatan pengguna, yaitu:

- **Tambah Catatan:** Membuat dan menyimpan catatan baru.
- **Lihat Catatan:** Menampilkan seluruh catatan yang telah dibuat.
- **Edit Catatan:** Memperbarui informasi pada catatan.
- **Hapus Catatan:** Menghapus catatan yang tidak diperlukan.
- **Cari Catatan:** Memudahkan pengguna menemukan catatan tertentu.

Fitur-fitur tersebut menggunakan konsep CRUD (Create, Read, Update, Delete) sebagai dasar pengelolaan data pada aplikasi.
