## Deskripsi singkat
Tugas ini berisi analisis kebutuhan aplikasi APK Catatan dengan domain pencatatan pribadi dan aktivitas mahasiswa. Dokumen mencakup deskripsi aplikasi, persona pengguna, kebutuhan fungsional dan nonfungsional, prioritas MoSCoW, user flow untuk proses membuat catatan, serta pemetaan kebutuhan fungsional ke halaman dan widget Flutter yang direncanakan.

## Isi folder
- `dokumen-kebutuhan.md` — dokumen utama, termasuk kode diagram Mermaid.
- `user-flow.png` — diagram user flow hasil ekspor untuk dibaca langsung.

## Refleksi (tepat 3 kalimat)
Bagian yang paling sulit saya tetapkan adalah prioritas kebutuhan dengan metode MoSCoW. Saya perlu membedakan fitur yang benar-benar wajib agar fungsi inti aplikasi berjalan dari fitur tambahan yang masih dapat ditunda tanpa menghilangkan tujuan utama pencatatan. Menentukan batas maksimal lima fitur pada kategori Must have membuat saya harus mempertimbangkan kebutuhan persona mahasiswa dan cakupan versi awal aplikasi.
